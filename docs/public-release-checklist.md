# Public Release Checklist

- Confirm all test data is synthetic.
- Remove private notes and internal-only links.
- Verify no tokens, kubeconfigs, real cluster URLs, screenshots with sensitive data, or real secrets exist in history.
- Add a LICENSE file only when public release is approved.
- Reconfirm Apache-2.0 suitability before adding the license.
- Tag the first release only after a full MVP works end-to-end.
- Confirm CI passes.
- Update README status and limitations.
- Prepare sanitized demo assets.
